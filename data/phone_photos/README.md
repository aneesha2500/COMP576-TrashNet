# Phone photos (Aneesha, Proposal Step 4)

Put real photos of waste items here, one item per photo, at least 20 per class:

    data/phone_photos/cardboard/IMG_001.jpg
    data/phone_photos/glass/...
    ...

Tips: everyday places (desk, floor, kitchen counter, outside), different lighting and angles,
the object roughly centered. Convert HEIC to JPG before adding (on a Mac: open in Preview,
File > Export > JPEG). Keep each photo under ~1 MB so the repo stays small.
These files are committed to git so all three of us test on the same photos.
